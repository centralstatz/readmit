## Submission context

This release updates `readmit` to version 1.0.0. The package retains its focus on hospital readmissions while evolving from its initial data and reporting utilities into the Readmission Risk Pool (RRP), a project-based framework for readmission risk assessment.

This release introduces a revised public API and changes the license from MIT to Apache License 2.0.
